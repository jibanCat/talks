The Lyman-alpha Forest

Reading the Universe and Galaxies in Shadows

Light from a distant quasar crosses the cosmic web before it reaches us. Diffuse hydrogen along the way absorbs the light at different wavelengths; together, these absorption features form what we call the Lyman-alpha forest.

This 20-minute public talk is built as a live web page. It reads that light through one simulated universe.
